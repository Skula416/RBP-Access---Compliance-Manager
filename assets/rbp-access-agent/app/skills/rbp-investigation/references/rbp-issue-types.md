# Common RBP Issue Types and Typical Fixes

| Module / Feature | Common Issue | Typical Permission Group | Change Type |
|---|---|---|---|
| Compensation | Cannot view or edit compensation information | Compensation Admin or Compensation Planner | assign |
| Performance | Cannot access performance reviews | Performance Management User | assign |
| Recruiting | Cannot see open positions or applicants | Recruiting User or Recruiting Recruiter | assign |
| Org Chart | Cannot see the organisational chart | Employee Self-Service (ESS) | assign |
| Leave Requests | Cannot approve leave requests | Manager Self-Service (MSS) | assign |
| Employee Profile | Cannot edit employee data | HR Admin or HR General | assign |
| Reports / Analytics | Cannot run workforce reports | Analytics Viewer or Report Admin | assign |
| Succession Planning | Cannot view succession plans | Succession Planner | assign |
| Learning | Cannot access learning courses | Learning User | assign |
| Admin Tools | Over-privileged user with admin access | Remove broad admin group | revoke |

**Note:** These are indicative mappings. Always confirm with the RBP GenAI Troubleshooting tool for the specific permission group name in the customer's configuration.
